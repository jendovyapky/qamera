# Qamera

Webová aplikace (PWA) na focení a úpravu fotek v mobilu – film a vintage: emulace starých filmů, filmové zrno, halace, barvy.

- Web: https://qamera.jendovyapky.eu
- Licence: GPL-3.0 (viz `LICENSE`). Filmové LUT ve složce `luts/` jsou pod CC BY-SA 4.0.

Film modeling powered by [spektrafilm](https://github.com/andreavolpato/spektrafilm) (Andrea Volpato).
Inspirace: [Spektrafilm for Android](https://github.com/thetechgeekko/Spektrafilm-android) by Akshay Sharma.
